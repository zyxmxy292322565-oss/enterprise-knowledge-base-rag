# GraphRAG 与图谱治理

图谱以知识快照为单位构建。规则抽取和可配置模型抽取生成实体及关系候选，保留 Child、文档版本和原文摘录。审核接口对实体或关系记录决策，封存前核对语料身份、数据结构与原文绑定。一个已存在的未封存图谱会阻止该快照发布。

查询先匹配审核后的别名，再在 MySQL 里沿审核关系做有界遍历。路径根据政策范围、日期和治理状态筛选，证据回到同快照 Child。原问与子问都可以查图，受图查询、跳数与总时间限制。实体歧义、政策冲突、证据缺失或必要路径超时会进入相应可靠性分支。
