# 评测中台与 Gold Evidence

创建带版本的数据集。问题记录预期动作和必需事实，证据记录文件内容 SHA-256、原文摘录及坐标。证据先映射到指定快照的 Child 可见区间，审核后冻结数据集。开发自审与独立人工评审分别记录。Holdout 有独立授权与审核边界。

运行绑定数据集摘要、快照、发布代次、代码及模型身份。检索模式记录候选与最终证据。回答模式可按配置走普通问答或可靠性控制器，并记录逐题 Trace。比较时区分候选召回、最终证据 Recall、动作匹配和引用支持。冻结样本结果只反映该样本及配置。

干净部署初始没有 Gold。可导入自己有授权的数据或用合成案例验证。历史原始运行和数据集不随仓库分发，历史接口依赖部署方提供相应资产和摘要匹配。
