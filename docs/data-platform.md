# 数据中台与知识快照

`POST /v2/documents` 上传 TXT/PDF 后生成草稿版本。TXT 优先 UTF-8，PDF 按页提取文本。Parent 对应页内段落，Child 默认 500 字符、100 字符重叠。原文与处理产物分开保存。引用的页号与起止坐标指向抽取文本，Child ID 包含文档技术版本。

构建时抓取就绪版本、草稿修订及基线代次，生成 Child 向量、BM25、父子关系和原文身份清单。索引、回执、清单校验通过后才能发布。图谱在同一快照下独立构建，有草稿图谱时需要审核封存才能发布。

发布提交以期望代次和幂等键校验，锁定 MySQL 活动指针并提交新代次。旧请求继续使用原先固定的快照。回滚仅接受曾发布的快照，恢复其索引、文档版本及父子关系，同时生成新缓存代次。上传与草稿删除不会立即改变在线查询。
