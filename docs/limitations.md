# 已知限制

- 本地 Compose 用于可复现演示。高可用、公开服务入口、多租户隔离、备份策略与容量规划需要单独设计和验收。
- PDF 依赖可抽取文本，页码和偏移指向抽取文本。扫描文档 OCR 和精细版面坐标没有接入此路径。
- 人工审核决定图谱与 Gold 的适用范围。规则和模型可出错，定向真实模型记录、单题演示和压测样本只适用于所用条件。
- Parent 取页内段落，在线按需补邻文。已有去重粒度是 Child 行和 Parent ID。重叠正文的区间合并、普通问答完整输入的精确 Token 上限仍是可改进项。
- 默认索引是 Milvus 精确 FLAT/L2。代码仍保留 FAISS 历史恢复和旧接口兼容所需的路径及依赖。
- 干净部署从空数据启动。语料、历史评测原始资产、备份、模型权重与私有运行清单由操作者单独准备。
